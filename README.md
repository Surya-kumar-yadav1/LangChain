LangChain Learning Repository

A hands-on repository for learning and implementing LangChain, exploring LLM application development, embeddings, vector databases, and Retrieval-Augmented Generation (RAG).

The goal of this repository is to understand how LangChain works through practical Python implementations.

🚀 Technologies Used

Python – Primary programming language.

LangChain – Framework for building LLM-powered applications.

ChromaDB – Vector database for storing and retrieving document embeddings.

Hugging Face – Local embedding models using Sentence Transformers.

Sentence Transformers – Generating semantic embeddings.

📚 Topics Covered

LangChain fundamentals

Document loading and processing

Text splitting and chunking

Embeddings and semantic search

Vector databases

ChromaDB integration with LangChain

Similarity search and retrievers

Retrieval-Augmented Generation (RAG)
